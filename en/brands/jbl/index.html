What the Mac doesn’t hear from a 770NC

Besides the audio link, the LIVE 770NC exposes a separate Bluetooth LE control service. The adapter subscribes to it and logs a notification if the headset sends one when its noise mode changes.

Passive means the Mac sends the headset no commands. If you change the mode with the button and a notification arrives, the Mac sees it; if none arrives, nothing happens.

Battery isn’t read by this adapter. If the headset reports battery to macOS, the macOS value shows.

Which JBL models?

Only the JBL LIVE 770NC. Tune, Tour and other Live models are not matched in this build and stay with macOS. If you spot the same LE service on another model, report it; the list grows on evidence.

2-minute test

About two minutes from install to report. “Nothing answered” is a useful result too: it is how we learn which models don’t respond.

  1. Install the TestFlight beta; the JBL adapter ships in 1.5 (14).
  2. Connect the 770NC in System Settings → Bluetooth.
  3. In Settings → Brands → Experimental brand adapters turn on the JBL switch. It is off by default; in 1.5 (14) the label may read in Turkish: “JBL verisini oku (deneysel)”.
  4. Reconnect the headset, then change the mode once with its button.
  5. Copy the diagnostic report: in 1.5 (14) open the main window’s Device → “Report my device”; in 1.6 it is Settings → Diagnostics → Copy report. The report contains no Bluetooth name, address or serial number.
  6. Open the TestFlight app, pick Headphone Control, choose Send Beta Feedback and paste the report. These are the reports the verification dashboard counts.

Questions

Is there an official Mac app for JBL?

JBL’s official headphones app runs on iPhone and Android; its App Store listing (checked 26 November 2026) offers no Mac version. On a Mac the LIVE 770NC plays audio, but you can’t see its noise mode.

Can I turn ANC on a LIVE 770NC on from the Mac?

No. The adapter is passive; it only listens to notifications the headset sends.

Why is there no battery percentage?

The adapter doesn’t read battery. Any battery you see comes from macOS; if the headset doesn’t report it to macOS, it stays empty.

What about the Tune 770NC or Tour One M2?

They are not matched in this build. Universal sound handoff is available.

Does the number of reports change the status label?

No. The verification dashboard shows the number of successful TestFlight reports next to each model’s label. The count never replaces the label, and no fixed number turns a model into “verified”.
