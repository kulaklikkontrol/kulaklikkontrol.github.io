Samsung’s old Mac tool for Galaxy Buds only updates software

Samsung documents Galaxy Buds Manager, a computer tool for Windows and macOS 10.8 or later, only for updating Galaxy Buds and Buds+ software; we haven’t checked whether it still runs on current macOS. What Galaxy Buds are missing on a Mac

Older Buds (Galaxy Buds 2019, Buds+, Buds Live, Buds Pro) send status messages on their own while connected. The adapter listens to them: earbud and case battery, and whether the buds are in your ears.

The adapter writes nothing. ANC, ambient sound, EQ and touch settings don’t change from the Mac, and the ANC state on Buds Live and Buds Pro isn’t shown in this build.

Galaxy Buds2, Buds2 Pro, Buds FE, Buds3 and later are not matched; the Mac side is planned. Those models only keep the experimental universal layer, which hasn’t been tried on any Buds model either.

Which Galaxy Buds?

Four models are matched: Galaxy Buds (2019), Buds+, Buds Live, Buds Pro. From the Buds2 generation on, the message layout differs, so those are out of scope in this build.

2-minute test

About two minutes from install to report. “Nothing answered” is a useful result too: it is how we learn which models don’t respond.

  1. Install the TestFlight beta; the Samsung adapter ships in 1.5 (14).
  2. Connect the Buds in System Settings → Bluetooth.
  3. In Settings → Brands → Experimental brand adapters turn on the Samsung switch. It is off by default; in 1.5 (14) the label may read in Turkish: “Samsung Galaxy Buds pilini oku (deneysel)”.
  4. Reconnect the Buds and take them out of the case; battery messages arrive whenever the buds send them.
  5. Copy the diagnostic report: in 1.5 (14) open the main window’s Device → “Report my device”; in 1.6 it is Settings → Diagnostics → Copy report. The report contains no Bluetooth name, address or serial number.
  6. Open the TestFlight app, pick Headphone Control, choose Send Beta Feedback and paste the report. These are the reports the verification dashboard counts.

Questions

Is there an official Mac app for Samsung Galaxy Buds settings?

Samsung documents Galaxy Buds Manager, a computer tool for Windows and macOS 10.8 or later, only for updating Galaxy Buds and Buds+ software; we haven’t checked whether it still runs on current macOS. Settings live in Samsung’s official app on Android, and the iPhone app supports only Buds+ and Buds Live (checked 26 November 2026). On a Mac, older Buds play audio but their battery details stay hidden.

Will Buds3 Pro show battery on a Mac?

The adapter doesn’t recognise the Buds3 Pro. If the earbuds report battery to macOS, the macOS value shows.

Does the adapter write anything to the earbuds?

No. It only listens and doesn’t touch the earbuds’ settings. If nothing answers, the basics keep running.

Can I change ANC on Buds Pro from the Mac?

Not in this build; the adapter is limited to battery and in-ear state.

Does the number of reports change the status label?

No. The verification dashboard shows the number of successful TestFlight reports next to each model’s label. The count never replaces the label, and no fixed number turns a model into “verified”.
