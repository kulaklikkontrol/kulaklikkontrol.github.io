How the count works

  • Counted: successful reports sent through TestFlight → Send Beta Feedback with the diagnostic report pasted in.
  • Public posts and comments go in the last column. We can’t check them, so they are not counted.
  • The count sits next to the label and never replaces it. No number of reports turns a model into “Verified”; only a test on our own hardware changes a label.
  • A “nothing answered” report is welcome too. It shows up in the scope column as a known limit, not in the count.

Send a report in 2 minutes

  1. Join the beta: TestFlight link, then Accept and Install (macOS 14+).
  2. Turn on your brand’s adapter in Settings → Brands → Experimental brand adapters and connect the headset.
  3. Copy the diagnostic report: in 1.5 (14) the main window’s Device → “Report my device”; in 1.6 Settings → Diagnostics → Copy report. It contains no Bluetooth name, address or serial number.
  4. In the TestFlight app choose Headphone Control → Send Beta Feedback and paste the report.
